# 표준물류단가 산정 시스템 (standard_cost)

TPL(3자물류) 영업팀용 **데이터 업로드 기반 견적 도구**.
화주 실적 데이터(출고내역·상품마스터·재고·입고)를 표준 양식으로 업로드하면
물동 프로파일을 자동 추출하고, 자사 원가 마스터와 결합해
**작업비 · 보관비 · 배송비 → 항목별 견적 단가**를 산정한다.

> 계산에 들어가는 **모든 가정(A1~A25)·수식·한계·필요조건**은
> [docs/DESIGN.md](docs/DESIGN.md) 참조 (앱 내 "설계·가정 문서" 메뉴로도 열람 가능).

## 실행

```
pip install -r requirements.txt
python app.py          # http://localhost:5001
```

Windows는 `표준단가 서버실행.bat` 더블클릭.

## 사용 흐름

1. **견적 생성** → 화주사명 입력
2. **① 데이터 업로드** — 표준 템플릿(화면에서 다운로드) 또는 자사 수주일보(WMS 영문 양식) 그대로
   - 출고내역(필수) · 상품마스터(권장) · 재고 스냅샷(선택) · 입고내역(선택)
3. **② 물동 프로파일** — 자동 추출값 확인, 필요 시 보정(예: "내년 물량 2배")
4. **③ 원가 파라미터** — 마스터 기본값 확인, 견적별 보정 / 배송비 모드 선택
   - 배송비: ①직접입력 ②권역 단가표×물량분포 ③배송비단가시스템(delivery_pricing) 연동
5. **④ 결과** — 항목별 견적 단가표(입고/출고/보관/배송) + 인력 소요 + 민감도 → **견적서 엑셀** 출력

## 구조

| 파일 | 역할 |
|---|---|
| `app.py` | Flask 라우트 (포트 5001) |
| `profile_extract.py` | 업로드 파싱 + 물동 프로파일 추출 (DESIGN.md §2·§3) |
| `engine.py` | 원가·단가 산정 엔진 + 기본값 seed (§4·§5) |
| `models.py` | CostParam · WorkProcess · RegionRate · Quote |
| `delivery_bridge.py` / `delivery_link.py` | 배송비단가시스템 연동 (모드③) |
| `docs/DESIGN.md` | 설계·가정·한계 문서 |

## 주의

- seed된 생산성·시급·임차료 등은 **개략값** — 실측·계약값으로 교체 후 견적 확정할 것 (§7 체크리스트)
- 산출 단가는 부가세 별도 원가 견적이며 계약단가가 아님
